# (via `--list`) by the campaign runner and the static gap gate
# (cmd/evener-fuzzcov -gap-only). Each entry is "tag:module:package-relpath:name[:coverpkg]":
#   tag       "native" — a testing.F target driven by `go test -fuzz`; or
#             "rapid"  — a Test* func driven by rapid.Check during ordinary
#             `go test -run`; or "test" — a support-only reachability check.
#             Native and Rapid rows are machine-checked against source.
#   module    the go.work module dir ("." or "agent"/"llm"/"auth").
#   package-relpath  the package relative to that module.
#   name      the FuzzXxx (native) or TestXxx (rapid/test) function name.
#   coverpkg  optional: the package(s) the target really exercises, when that
#             differs from the package it lives in (FuzzToolArgsValidate lives
#             in the agent root but covers ./internal/tool). Read by the static
#             gap gate; comma-separated for several.
