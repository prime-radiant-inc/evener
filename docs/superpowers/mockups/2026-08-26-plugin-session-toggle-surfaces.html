Exact-set semantics

Untouched means “inherit current defaults.” Any edit creates an explicit allow-list. Choosing None is a real empty list, not an omitted field.

Source clarity

Rows show marketplace refs or directory origins, while manifest name remains the runtime selection key and uniqueness boundary.

Honest failures

Preview diagnostics remain visible. If a selected plugin disappears before Start, startup stops and asks the user to refresh instead of silently dropping it.
