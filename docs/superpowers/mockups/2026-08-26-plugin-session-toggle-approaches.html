Architecture common to all three

A new launch-preview RPC resolves layered pluginDirs plus globally enabled registry entries, validates and deduplicates by manifest name, and returns the exact candidate set. Once the user edits that set, the UI sends the selected manifest names as a one-session allow-list. The server filters before sandbox roots and before skills, agents, commands, hooks, and MCP initialize. Global enable/disable state never changes.
