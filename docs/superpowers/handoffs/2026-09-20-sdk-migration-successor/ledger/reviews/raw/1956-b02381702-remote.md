## Summary

The series wires offline keybinding-draft recovery into the native app. It adds a store-free probe/discard path in `NativePreferencesProvider` (`offlineDraftUnreadable`, `offlineStorageUnavailable`, `discardUnreadableKeybindingsDraft`), extracts the production `rawStringDraftBackend` so tests exercise the real parse/compare code over a Map-backed fake, replaces the string-tagged draft markers with symbol brands that `JSON.parse` can never reproduce, and refactors the shared store's `restoreDraft` field projection into a reusable `decodeKeybindingDraftFields`. Tests cover the probe, the unreadable/JSON-null cases, readable-replacement refusal, live-model reclassification, storage failure, and hub-switch reset.

The core logic reads correctly: the probe guards storage failures from record-decode failures, the discard distinguishes `refused`/`removed`/`absent` from `storageUnavailable`, the follow-up re-read (not the discard's own result) decides whether the notice stays, and the nudge is gated on the bound model matching the current hub/client so a stale model is never touched. I found no high- or medium-severity bugs.
