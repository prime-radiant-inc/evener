## Medium

- **`cmd/evener-hub/main_background.go:26,79,93`** — Background seeding, GC, and auto-upgrade still construct separate managers rooted at the default path (`""`) instead of reusing the injected `web.cfg.PluginManager` (rooted at `cfg.PluginRoot`). With a non-default `PluginRoot`, these paths can mutate the default store while RPCs use the configured store, violating the one-manager-per-hub invariant. **Fix**: Use `web.cfg.PluginManager` for all three maintenance paths (or at minimum construct each manager from `web.cfg.PluginRoot`), and add a test using a temporary `PluginRoot` that verifies background writes stay under that root.

## Low

- **`internal/plugins/paths.go:31`** — The `storeChangedMu` comment still names functions deleted by this diff (`resetStoreChanged`, `captureStoreChanged`). Surviving operations are `markStoreChanged`, `takeStoreChanged`, `OnStoreChanged`, and direct reads in `store_changed_test.go`. Reword to name the current operations (e.g. "mark, take, install/read") so future readers aren't misled about how a stale flag is prevented.

- **`cmd/evener-hub/web.go:161`** — The production-only wiring step (`wirePluginStoreBroadcast(web.cfg.PluginManager, server)`) has no test that would fail if deleted. Existing tests inject their own manager or only assert the pointer/root; if this line regressed, all hub RPC plugin-store writes would go unbroadcast (the #1734 bug) and the suite would still pass. A test that builds a `WebServer` against a temp `PluginRoot`, triggers a store write through `web.appRPC` (e.g. marketplace add), and asserts the connected client receives `evener/marketplace/updated` would close the loop.

- **`cmd/evener-hub/app_rpc.go:514`** — The nil fallback creates an unwired manager that is still used by plugin mutation and check-now handlers, so servers built directly through `newHubAppServer`/`newHubAppServerWithNavigation` no longer broadcast store writes. **Fix**: Wire the fallback manager to the server it creates, or remove the fallback and require callers to provide a manager already wired to that server.
