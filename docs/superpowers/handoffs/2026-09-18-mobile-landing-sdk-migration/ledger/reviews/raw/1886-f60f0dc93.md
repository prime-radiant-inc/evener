## Summary

This commit continues the D25 migration by moving two framework-free pieces out of the web app and into the shared AppWire package:

- `state/mutation/commitFeed.ts`: extracts the inline `subscribeMutationPersistence` handler from `pendingTurnsStore.ts` into a reusable `wireMutationCommitFeed(store, fence, feed, refresh)`. It keeps the same semantics — apply a live commit synchronously (advance the fence, record provenance, land the outbox record, retire a resend's recovery entry) and then fire a refresh for the feed's named targets (or all targets when none are named).
- `state/mutation/projectionWork.ts`: extracts the in-flight projection-work set and its 4s stall tripwire/macrotask-yield into `createMutationProjectionWorkTracker(ports)`, with browser globals injected as ports.

The frontend now binds the tracker to `setTimeout`/`setInterval`/`MessageChannel` and binds `wireMutationCommitFeed` to `subscribeMutationPersistence` and `refreshPendingTurnsProjection`. Both new modules are added to `tsconfig.build.json`, exported from the mutation barrel, and covered by new unit tests. The extraction preserves the previous ordering and semantics (fast path before refresh, snapshot of outstanding work taken synchronously, yield after the race), so no behavioral regression is apparent.
