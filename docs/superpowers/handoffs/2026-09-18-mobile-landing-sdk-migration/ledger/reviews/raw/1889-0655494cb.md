- `saveRegistry` (commit `cff073c`) and `saveMarketplaces` (commit `0655494`) now log the raw `*fs.PathError`/`atomicWriteFile` error to `m.stderr()` and return a generic `"saving <file> failed; see the hub's log for detail"` error, covering every caller at the shared write boundary.
