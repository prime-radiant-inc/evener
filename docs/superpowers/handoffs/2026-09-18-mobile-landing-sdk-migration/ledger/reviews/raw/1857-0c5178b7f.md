The three commits extract the pending-turns durable-read "projection fence" from the web app into the shared `@evener/appwire-client/state/mutation` package, then switch the web to consume it.

Types line up (`readMutationPersistence` structurally satisfies `MutationPersistencePort<MutationAttachment>`), no stale references to the removed module-level state remain, and the qualification runner derives the new value/type surface from the entry module, so no manifest update is required.
