## Summary

This 45-commit series is a substantial hardening of the shared keybindings draft editor (`@evener/appwire-client`) and its native consumer. It:

- Extracts the checkpointed-draft port/repository (`draftCheckpointPort.ts`) and the settings-hub generation helpers (`settingsHubGeneration.ts`) into reusable modules.
- Gives the draft port atomic `insertIfAbsent`/`replaceIf` (closing the first-write and lost-revision races) and makes `removeIf`/`replaceIf` take a raw-or-decoded identity so unreadable records remain removable.
- Adds a durable draft `generation` stamp so a hub replacement that coincidentally reports the same revision is still detected as stale, and reworks when a generation is "earned" (authoritative payload / rebase only).
- Introduces unreadable-record classification/typing, a store-free discard path (`discardStoredDraft`), and native offline recovery UI for it.
- Reworks write fencing (direct vs checkpointed writes sharing one token, reservation-at-call-time), deferred settles that publish even when local reconcile throws, and CAS refusals that adopt the replacement instead of reporting a storage failure.
- Replaces the old in-memory test double with a shared canonical-comparison fake (`testing/draftStorage.ts`) and a native `fakeDraftBackend`, with broad test coverage.
