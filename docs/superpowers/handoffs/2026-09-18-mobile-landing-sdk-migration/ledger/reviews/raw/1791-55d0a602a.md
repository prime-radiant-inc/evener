## Review Findings
- **Severity**: Medium
- **Location**: `mobile-native/src/NativePreferencesProvider.tsx:113`
- **Problem**: The cold-offline effect calls `nativeKeybindingDrafts(...).load()` without handling storage-port errors, even though the draft-port contract permits every method to throw. A failed `Storage.getItemSync` in the exact offline path this feature targets can throw inside `useEffect` and take down the provider rather than showing recovery or storage-unavailable state.
- **Fix**: Wrap the probe in a `try/catch` and surface a distinct offline storage-failure state through the provider; preserve the unreadable flag only after a successful read.

---
- **Severity**: Medium
- **Location**: `mobile-native/src/nativePreferenceDrafts.ts:144`
- **Problem**: `parseDraftBytes` represents both stored JSON `null` and the stored JSON string `"null"` as the same primitive string. `nativeTranscriptDrafts` consequently treats a present, invalid JSON string as no draft, violating the transcript repository’s contract that corrupt checkpoints must be rejected rather than silently treated as empty.
- **Fix**: Use a distinct sentinel for parsed JSON `null`, teach the byte matcher to recognize that sentinel for keybindings removal, and let the string `"null"` continue into transcript validation.

---
- **Severity**: Low
- **Location**: `appwire-client/typescript/testing/draftStorage.ts:45`
- **Problem**: Both new in-memory fakes can report compare-and-swap success for an absent record when the supplied identity is `null` or `undefined`, because `JSON.stringify` collapses those comparisons. This violates the contract that `removeIf`/`deleteIf` and `replaceIf` report whether an actual record was removed or replaced. The same issue exists in `mobile-native/src/draftBackend.testkit.ts:28`.
- **Fix**: Return false before serialization whenever no record is stored, for both removal and replacement paths, in both fakes.

## Summary
The change centralizes atomic draft checkpoint persistence, tightens keybindings write fencing and unreadable-draft recovery, and projects those states into native preferences.
