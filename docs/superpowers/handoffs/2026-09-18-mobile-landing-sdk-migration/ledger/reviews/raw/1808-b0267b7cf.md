- **Severity**: Medium
- **Location**: `appwire-client/typescript/keybindingsStore.ts:1202`
- **Problem**: `persistDraft` treats `drafts.save()` CAS refusal the same as a storage throw, sets `storageUnavailable: true` and leaves the stale classification in place, so a concurrent-writer race reports disk failure and retries against the same stale identity instead of adopting like `discardDraft`/`settleWrite` do.
