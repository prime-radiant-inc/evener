######## member 2 (pi default)
## Summary

The three commits tighten how warning-frame strings are handled before they enter the model. `hasWarningText` now answers "is there content?" with a non-allocating `/\S/` scan instead of a bounded-copy-then-`trim`, which also fixes a misclassification where >2000 leading blank code points hid real content. All string bounds now funnel through one `boundedPrefix(s, maxCodePoints, start = 0)` primitive: it slices a UTF-16 window (`maxCodePoints * 2` units) before expanding via `Array.from`, strips a trailing lone high surrogate, then keeps the first `maxCodePoints` code points. `prunedForStringify` uses it for values and keys; `boundedCodePoints`/`rawWarningFrame` use it for the JSON fallback; and `boundedContent` uses its `start` window to keep the bounded prefix of the *content* rather than leading padding. `foldWarningParams` now bounds `text`, `title`, `hint`, and `source` so no oversized field reaches `ItemModel`. The added tests exercise surrogate boundaries, the pre-`Array.from` allocation bound, per-field bounding, no-`trim`, and leading-padding misclassification.

I verified the core boundary math (a `2 * maxCodePoints`-unit window always contains ≥ `maxCodePoints` code points, and stripping a trailing lone high surrogate leaves at least that many), that `\S` and `trim()` agree on the ECMAScript whitespace set, and that the `start` index from `/\S/` cannot land mid-surrogate-pair for well-formed input.

---

**Severity: low** — `appwire-client/typescript/reducer.ts:1017-1018`

The `hasWarningText` comment says bounding "happens separately ... (`boundedCodePoints` below, applied at each call site that assigns into the model)." The helper actually applied at every assignment site in `foldWarningParams` is `boundedContent`, not `boundedCodePoints` (`boundedCodePoints` is only used inside `rawWarningFrame`). A future maintainer following the comment would look at the wrong function to understand which bound governs stored warning fields. Suggested fix: change the reference to `boundedContent`.
