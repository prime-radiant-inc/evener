**Location**: `appwire-client/typescript/reducer.ts:1018`  
**Problem**: `hasWarningText` only trims the first 2,000 code points. A warning beginning with more than 2,000 whitespace characters followed by meaningful text is classified as blank, causing the actual warning to be discarded.  
**Fix**: Detect non-whitespace content by scanning the original string without allocating a full copy, then apply truncation only when storing/displaying it.

- **Severity: low**
  - **File/line:** `appwire-client/typescript/reducer.test.ts:4767` (the test `"an oversized warning frame's fallback bounds a many-key object..."`), covering `prunedForStringify`'s `RAW_WARNING_FRAME_MAX_NODES` in `appwire-client/typescript/reducer.ts`.
  - **What goes wrong:** This test is the only claimed coverage for the total-node budget, but it passes a *flat* 100,000-key object (`params.extra = manyKeys`). That shape is already fully bounded by the per-object key cap (`RAW_WARNING_FRAME_MAX_OBJECT_KEYS = 50`): the prune touches at most ~54 nodes, so `RAW_WARNING_FRAME_MAX_NODES` never becomes the limiting factor. If the node budget were removed or regressed, this test would still pass. The gap it claims to close — a tree whose *node count* is large while every individual container stays within the per-level caps (e.g. 50 arrays each holding 50 objects, nested a few levels: bounded per level, but up to 50^6 nodes without the budget) — has no coverage. A regression there would let a malformed warning frame make `JSON.stringify` walk an enormous pruned tree, the exact O(frame-size) cost this commit exists to prevent.
  - **Suggested fix:** Add a test that builds a breadth×depth structure exceeding 500 total nodes while keeping each array/object within its per-level cap (e.g. recursively nest `Array.from({length: 50}, () => ({ ...50 keys... }))` two or three levels), then assert the fallback output stays bounded (or spy on the property reads / `JSON.stringify` output length). Such a test fails when the node budget is removed, unlike the current flat-object test.
