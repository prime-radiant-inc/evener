Fixtures across web/mobile now emit/stamp `askPending` accordingly.

I verified the server support (`stampAskPendingOnStatusChange`, `Envelope.AskPending`, `clearAskPending` call sites, steering-kind/source values) already exists outside the diff and that the client gate/status-absent-means-no-update rule is coherent with it.
