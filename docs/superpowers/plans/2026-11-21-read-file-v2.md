# `read_file` v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Evener's `read_file` (and shared `memory_read`) to engine-owned head-only line-boundary paging with per-line clamping, negative-offset tail reads, compact tab-aware prefixes, range-aware repeat tracking with compaction reset, pure-Go image downscaling and PDF `pages` slicing, plus fix the `system.md.tmpl` copy-before-read prompt confounder.

**Architecture:** `agent/execenv` owns text window formatting, line clamping, head-only byte budgeting (`48_000` bytes), exact/bounded footers, and backward tail reads through a single shared renderer exposed via optional `RichFileReader` (`ReadFileMeta`) while `ReadFileCtx` and `ReadFileAndBytesCtx` stay byte-identical; `agent/internal/tool` switches `read_file`/`memory_read` to a thin `schema.TruncHead` (`50_000` chars) safety net and passes `ReadFileMeta` / `ReadPages` through `ExecResult` to `agent/session_read_repeat.go`; `llm/image_scale.go` downscales oversized images using the existing `golang.org/x/image` dependency and `agent/internal/pdfslice` slices PDFs in memory with `github.com/pdfcpu/pdfcpu v0.16.4`.

**Tech Stack:** Go (`go.work` modules `llm` and `agent`), `golang.org/x/image v0.48.0` (already in `llm/go.mod`), `github.com/pdfcpu/pdfcpu v0.16.4` (Apache-2.0, pure Go `CGO_ENABLED=0`, added to `agent/go.mod` only), `tools/tool-fluency` YAML probes.

**Spec:** `docs/superpowers/specs/2026-11-21-read-file-v2-design.md`

## Global Constraints

- **Budget caps (package-level `var`s in `agent/execenv` for test overrides):** `DefaultReadLines = 2000`, `DefaultReadMaxBytes = 48_000`, `DefaultReadMaxLineChars = 2000`, `ReadTotalLinesScanCap int64 = 2 << 20` (2 MiB, chosen below `TestReadFileWindowReadsOnlyTheWindow`'s existing 4 MiB O(window) I/O contract so that guarantee stays untouched).
- **Registry backstop:** `read_file` and `memory_read` use `schema.ToolOutputLimit{MaxChars: 50_000, Strategy: schema.TruncHead}`; `execenv` footer must never be truncated by the 50,000-char registry cap.
- **Byte-for-byte equivalence & sandbox parity:** `ReadFileCtx` and `ReadFileAndBytesCtx` must produce byte-identical output for the same file and arguments at every size (`read_window_equivalence_test.go`). All three `fileTarget` arms (`off`, `sandboxFS`, `scratch`) must honor identical admission and cancellation (`file_op_arm_parity_test.go`, `read_window_sandbox_unix.go`, `read_window_sandbox_other.go`).
- **Interface compatibility:** Keep `execenv.ExecutionEnvironment.ReadFile` signature unchanged; expose `ReadFileMeta` via optional `RichFileReader` so existing test doubles stay untouched.
- **No contentless duplicate stubs:** `session_read_repeat.go` always returns full content in `res.Output` and resets `priorReads` on `publishFoldedHistory` without clearing `readFiles`.
- **Module boundaries:** Zero new dependencies in `llm/go.mod` (use existing `golang.org/x/image/draw`). `github.com/pdfcpu/pdfcpu v0.16.4` belongs exclusively in `agent/go.mod` behind `agent/internal/pdfslice` with `api.DisableConfigDir()` in `init()`.
- **Media caps (package-level `var`s):** `MaxModelImageDimension = 2000`, `MaxModelImageBytes = 4_500_000`, `MaxScalableImagePixels = 36_000_000` (existing `maxDecodedImagePixels = 16_000_000` in `llm/media_utils.go` stays untouched); `MaxUnpagedPDFPages = 10`, `MaxPDFPagesPerCall = 20`, `MaxModelPDFBytes = 20 << 20`.
- **Testing & copy rules (`docs/developing-evener/testing.md`):** Never assert on prose copy or error phrasing; assert behavioral invariants (line ranges, byte bounds, UTF-8 validity, decoded dimensions, extracted PDF page count, `UnchangedSinceTurn`, sentinel errors). Every `DefReadFile` parameter carries a non-empty `description`. Supported platforms: Linux and Darwin (`GOOS=windows` compile-only via build tags).

## Review Focus

1. **Non-UTF-8 lines and multi-byte UTF-8 boundary clamping (Task 1):** Short non-UTF-8 lines (e.g. `caf\xe9 \xff\xfe`) must pass through raw bytes untouched (never corrupted to `\ufffd` by `[]rune`), while multi-byte UTF-8 lines exceeding 2,000 runes or 48,000 bytes must slice cleanly on a rune boundary without producing invalid UTF-8.
2. **`memory_read` large-page note and `MEMORY.md` index no-double-footer (Task 1 & Task 2):** Returning `tool.TextResult` from `execFileReadWith` must not break `execMemoryRead`'s `size > memoryPageSizeLimit` note (`out.(string)` check must handle `tool.TextResult` too), and `MEMORY.md` generated index reads (`execenv.NumberLines` + `memoryIndexSliceFooter`) must not emit a duplicate `[Showing lines ...]` footer.
3. **Large-file (`> ReadTotalLinesScanCap`) backward tail seek edge cases (Task 1):** Backward 64 KiB `ReadSeeker` scans on `>2 MiB` files must still refuse NUL bytes in the scanned tail, emit real 1-based line numbers if the backward scan reaches byte 0, emit unnumbered lines (never fabricated `1\t`) when stopping past byte 0, and stay byte-identical with `ReadFileAndBytesCtx`.
4. **Same-size/same-mtime rewrite and media hash in repeat tracking (Task 2):** An atomic rewrite preserving `size` and `mtime` must not falsely trigger a repeat on an exact-range text re-read or media re-read (hash `res.ImageData` for media, `res.RecoverableOutput` for text), and `publishFoldedHistory` must clear `priorReads` while keeping `readFiles` intact.
5. **Media bombs, animated GIFs, non-PDF `pages`, and config-dir hermetism (Task 3 & Task 4):** A >36 MP PNG header bomb is rejected via `image.DecodeConfig` before pixel decode; an animated GIF over 4.5 MiB is rejected rather than flattened to frame 0; passing `pages` on a text or image file returns an error; `pdfslice` writes zero files under `$HOME` / `$XDG_CONFIG_HOME`.

- [ ] **Step 3: Implement range-aware `priorReads`, compaction clear, and `execFileReadWith`/`execMemoryRead` wiring**

Implementation notes:
- `priorReadSpan` holds `{startLine, endLine int; pages string; stamp readStamp; content [sha256.Size]byte; turn, repeatCount int}`.
- In `noteReadFileRepeat(path string, before readStamp, res *tool.ExecResult)`:
  - Skip if `res.ReadPastEOF || res.ReadUnnumberedTail`.
  - Hash `res.ImageData` when `len(res.ImageData) > 0`, else `[]byte(res.RecoverableOutput)`.
  - If stored spans for `path` have a different `stamp`, discard them.
  - Text reads (`res.ReadStartLine > 0 && res.ReadEndLine >= res.ReadStartLine`): match any span where `sp.startLine > 0 && sp.startLine <= res.ReadStartLine && sp.endLine >= res.ReadEndLine` AND (if `sp.startLine == res.ReadStartLine && sp.endLine == res.ReadEndLine`, require `sp.content == nowHash`).
  - Media reads (`res.ReadStartLine == 0`): match any span where `sp.startLine == 0 && sp.pages == res.ReadPages && sp.content == nowHash`.
