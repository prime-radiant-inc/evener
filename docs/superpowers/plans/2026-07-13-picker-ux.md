# Picker UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the shared directory picker behave like a click-navigable directory browser and polish the spawn model picker rows.

**Architecture:** Keep the directory change in `cmd/serf-hub/assets/dir-picker.js` so spawn and settings use the same behavior. Reuse the existing `completeDirs(prefix)` contract by passing the currently browsed directory with a trailing slash to list immediate child directories. Keep model picker changes inside the existing flat grouped picker in `cmd/serf-hub/assets/spawn.js`.

**Tech Stack:** Browser JavaScript, JSDOM tests, existing serf-hub CSS.

## Global Constraints

- Use the smallest reasonable change.
- Do not add a new directory API unless the existing `completeDirs` behavior cannot support browsing.
- Directory rows navigate into directories; they do not accept the value.
- Avoid visible "choose directory" text.
- Tests must be deterministic and must not use provider credentials, network, quota, or ambient machine state.
