#3  User message + steering

Four ways to render the user's words — initial prompt and mid-turn steer — so they recede beneath the agent's prose. Each slice shows the same realistic turn: prompt → agent prose (the hero) → a mid-turn steer → a multi-steer flurry. Judge whether the prose visibly wins and whether you can still find what you said.

What ships today (the bug): the user's message renders as a loud, right-aligned, green-tinted chat bubble — the single loudest thing on screen. That directly violates core principle #2 (never emphasize the user's own messages). Steering also wrongly borrows the amber "needs-you" tick; amber is reserved for when the agent needs you, not when you spoke.

AGolden left “You” tag

Idea: the design-system baseline. Prompt and steer share one quiet grammar — a dim uppercase tag + muted text, no box. The steer adds a thin neutral tick (not amber); stacked steers tighten their spacing. + One grammar to learn; left-edge anchor makes turns scannable. − With many steers the repeated “You steered” rows still accumulate vertical noise.

BGutter margin-note

Idea: demote by position — the user's words live in a quiet left gutter, outside the reading column, so the prose column is never interrupted. Steers sit in the same gutter, one notch quieter (--ink-3, smaller). + The hero column reads as uninterrupted prose; steers feel like annotations. − Costs horizontal space; gutter cramps on narrow viewports and long prompts wrap awkwardly.

CHairline rail only — no tag

Idea: the quietest baseline. No “You” label at all; the user's words hang off a faint vertical rail and are recognised by muted color + the rail. Steers get an even fainter rail and a tiny inline steer marker. + Maximum demotion; nothing competes with the prose; almost zero chrome. − Loses the explicit “You”/“steered” legibility; new users may not parse who's speaking.

DCollapse-long-prompt + stacked “You steered ×N”

Idea: directly attacks the “a flurry of steers out-shouts the prose” case. A long prompt clamps to ~2 lines with an inline more; a single steer renders inline (like A), but two or more mid-turn steers coalesce into one quiet expandable “You steered ×N” row. Click to expand. + Steer noise stays constant regardless of count; long prompts don't dominate the top of the turn. − Coalescing hides steer text until expanded; one extra interaction to re-read what you said.
