Serf Web Hub — UX Mockup Gallery

21 areas worth improving, each explored as 4 alternatives you can react to. Open any card. Every mockup is built on the same correct design tokens (the golden 4-color system), so they're comparable. This is for reaction, not a finished design — tell me which directions to pursue.

Why this exists: a 6-lens persona review (scannability, craft, accessibility, calm/motion, edge-case legibility, wayfinding) found that the shipped hub added the new features (live thinking, liveness, subagent module, sidebar tiers, scroll pill) on top of the old visual system — which never adopted the golden grammar, and whose color tokens are conflated (needs-you = error = red; user/idle = green; subagent = purple). Many "improvements" below are therefore adopt-the-golden + variants, marked shipped gap.
