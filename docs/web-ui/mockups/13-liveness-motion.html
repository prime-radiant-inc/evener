Mockup #13 — Liveness & motion economy

During an active turn the UI should run one gentle alive cue at a time and keep its honesty: a "working" signal must never look identical to a hung agent. Four directions for where liveness lives and how it moves, plus a calm-vs-concern study of the "no updates for Ns" line.

Fixes for the shipped active turn: (1) it runs three desynced perpetual loops at once — livebar breathing dot (~2.6s) + a blinking stream cursor (~1.3s) + a status-dot pulse — which reads as fidget; (2) the honest "no updates for Ns" line is a per-second rising counter that reads as an anxiety meter; (3) a ticking elapsed timer is a fourth moving number; (4) golden (pinned strip) and hard-cases (in-flow line) disagree on where liveness lives.
Targets: one loop max · honest stall ≠ working · quantized quiet, not a rising counter · one livebar home.

This page uses real animation so the calm-vs-busy difference is visible. The loop count on each alternative is the number of perpetual animations playing in its panel — the target is 1. Turn on prefers-reduced-motion: reduce (OS "reduce motion") and the whole page stills — that is the a11y reference rendering.

Reduced motion is ON. Every loop on this page is stilled. Liveness now rests on static signals only (a solid dot, a phase label, a last-event name) — which is exactly why those static signals must already carry the meaning. If a panel looks dead now, its liveness was leaning on motion it shouldn't have.

BQuantized "quiet for ~Nm" loops: 1

Replace the per-second rising counter with a coarse, rounded bucket that changes only at a few thresholds — so the eye sees a stable word, not a meter climbing. Sub-threshold silence reads "just now"; longer reads "~30s", "~1m". The single breathing dot is still the only loop. Tradeoff: you lose the exact second (rarely needed mid-turn); the raw value can live in a hover tooltip for the moment you do want it.

CLast-event label, not a raw counter loops: 1

Instead of counting up "no updates for Ns", name the last real thing the agent did: "last: edited cache.go · 31s ago". The relative timestamp tells you when without a rising meter, and the event name tells you the turn is making real progress — far more reassuring than a number, and honest because it only changes on actual activity. Tradeoff: needs a meaningful event stream to label (tool start/finish, text deltas); during a genuinely silent think it falls back to a phase word ("thinking").

DAmbient edge-sliver livebar loops: 1

Move the alive cue out of the widget row and onto a thin sliver along the transcript's edge: a single slow, low-contrast shimmer travels it (~3.4s) — peripheral, never a number, never competing with the prose. The footer keeps only static facts (elapsed, phase). It is the calmest because the motion is at the rim of vision, not in the reading column. Tradeoff: an ambient edge can be too subtle — easy to miss "is it live?" at a glance, and a traveling gradient is the heaviest single loop here; keep it very low-contrast or it becomes a scanner-bar.

↧"No updates for Ns" — calm band vs concern band

The same honest fact (the agent has gone quiet) rendered for two regimes. The rule that ties them to motion economy: escalation removes the alive cue rather than adding a new one. A short silence is expected, so it stays neutral with the one breathing dot; once silence crosses the honest-stall threshold the dot stops breathing (a hung agent is not "alive") and turns solid amber with an action — no extra loop is ever introduced.
