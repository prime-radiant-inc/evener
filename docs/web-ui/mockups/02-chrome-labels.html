#2 — Chrome & labels

The shipped chrome leans on ALL-CAPS monospace tracked labels for tier headers, project names, status badges, and a ● WORKING status — the design system's single biggest amateur tell. Each alternative below is a real rendering of the same chrome (top bar, sidebar tier + project headers, live status label) so the four label treatments are directly comparable. Top bar is identity-only; mono is reserved for machine text (paths, counts, ids) — every human label is sans.

ASans, sentence-case + hairline divider
Tier headers become a quiet sentence-case word with a hairline rule doing the structural separation; projects/sessions read in natural case; status is plain sans where color carries the meaning. + Calmest, most "crafted". − Lower-contrast labels lean on the rule to feel like sections.
