#4 · Assistant hero & reading hierarchy

The agent's prose is the hero — it must win the page by size, space, and contrast, with the user's prompt demoted (the user knows what they said). Today's UI renders agent prose at the same size as the boxed user message, so the subordinate element reads heavier and the eye has no anchor. All four directions also replace the filled inline-code chip with the golden's quiet underline. Same transcript slice in each, so the hierarchy and inline-code treatment are directly comparable.
Hero = agent prose (full --ink) Demoted = user prompt (dim / smaller / inset) Inline code = quiet underline, not a chip One device = the panel frame; transcript inside stays boxless
ASize bump + user muted
Agent prose jumps to 18px; the user prompt shrinks and dims. Hierarchy from an unmissable size delta. Trade-off: the biggest type costs vertical space — fewer turns fit on screen, and long replies feel heavy.
YouThe auth token cache invalidates too aggressively — valid tokens get evicted early. Find the root cause and fix it, and check how the callers use it too.
I traced the cache and its seven call sites. The eviction sweep is the culprit: evictExpired() compares each entry against lastUsed instead of expiresAt, so any token idle longer than one sweep interval is dropped while it's still valid.
The callers are fine — they all read through Get() and never touch expiry directly, so a single fix at the sweep covers every site. The change is small:
  • swap the comparison field in evictExpired()
  • keep the existing sweep interval — timing isn't the bug
  • add a regression test for the idle-but-valid case

BWhitespace-led
Sizes stay near golden, but the agent block gets generous air and owns the left margin while the user prompt is inset. Calm, readable, low-ink. Trade-off: leans on disciplined spacing — short replies can look sparse, and big leading also costs height.

CFirst-sentence lede
Each reply opens with a larger, fuller lede (the takeaway); the body recedes below it. A scannable headline per turn without inflating the whole block. Trade-off: depends on the model front-loading the point — a throat-clearing first sentence becomes an awkwardly loud non-headline.

DContrast-only
The minimal change: every size matches today's golden, but the user prompt drops to dim while the agent holds full contrast (plus the underline inline code). A control study. Trade-off: subtlest of the four — for fast skimmers contrast alone may not pull the eye the way a size or space delta does.
