Round 2 — pick one of these

Primary — “Watch rows” recommended

Running work keeps the top of the Activity panel; watches get their own group beneath it, and only an abnormal watch is promoted to “Needs a look”. Count on the summary line, inline watch rows in the fold-out. Includes the edge states: idle-with-only-a-watch, abnormal, many, zero.

Variant — “Watches first”

Same rail. Watches lead the Activity panel, ordered by severity then name, with running work below. Honours the ask most directly and is the cheaper build (no new activity-tree row kind).

Round 1 — the directions the reviews rejected or partly kept

A — Inline glint

Watches are supporting cast: count on the summary line, one-line watch rows in the fold-out, slim Watches group above retained activity. Best visual craft of the three; the count never changes a decision.

open full size screenshot

B — Scheduled work

Watches as peers of jobs, one list ordered by “when it next does something”, watches inline in the activity tree, ended watches fold away. Best information hierarchy; its ordering key does not exist in the runtime.

open full size screenshot

C — Watchboard rejected by all four

Watches get their own grammar: summary line leads with “next in 4m”, cadence ticks, an “Armed” card band. Its countdown, ticks, progress track and “×6h” have no backing data, and it drops the subagent count to make room.
