#8 — Subagent module states

Four directions for the inline Subagents (N) module under load and at the edges: a healthy small fan-out, a heavy fan-out that overflows, one with a child that failed to run, and the trap case — a "running" subagent on a session that is no longer live, with no completion signal ever arriving.

Held constant across all four: one containment device (the single neutral box — rows are separated by space, never gridlines); every status is glyph-paired (✓ done · ⟳ running · ✕ failed · ? unknown) so it survives colorblindness; done recedes (neutral — a subagent that ran fine but found bad news is still neutral, with the bad news in its result text); a failed child stands out in red and is never folded into the done tally; and above all, liveness is honest — a spinner or a breathing dot means genuinely live work, full stop. A "running" child on a dead/notLoaded session is shown as terminal unknown, not as a spinner that runs forever.
AHonest-clock demotion + “?” unknown state
Closest to today's module, with the liveness made honest. While the session is live, a running row shows ⟳ + a ticking clock. The moment the session is no longer live, every still-"running" row demotes to a neutral “?”, freezes its last-known elapsed, and labels it “last seen Ns ago” — so a dead subagent can never wear a spinner forever. Trade-off: the smallest visual change (good for adoption), but it leans on row text to carry the unknown state rather than a distinct layout.

Stale / terminal-unknown — session no longer live, no completion signal
Subagents (3)✓ 2 done · ? 1 unknownsession ended · last update 6m ago

The ? row is the whole point: it was "running" when the session went dark and no JOB_FINISHED arrived. Instead of a spinner that ticks forever, it freezes (~0:51, the ~ admits it's approximate) and says so plainly. The breathing dot and ⟳ are gone — nothing here is live.

BColumnar overflow, sorted by severity
Heavy fan-out becomes a tidy two-column grid sorted worst-first (failed → running → done → unknown), so a failure is always at the top and the rest pack densely instead of spilling into a run-on line. Past a cap, the tail folds to an honest “+N more · expand”. Trade-off: the grid sacrifices the live-spawn order (you can't watch them appear in sequence) for triage-at-a-glance; the two-up layout needs the result text to stay short.

Stale / terminal-unknown — running children that never reported back
Subagents (4)? 1 unknown · ✓ 3 donesession ended · last update 6m ago

Unknown sorts just under failed (it might be a failure we never heard about), so a session that died mid-fan-out still surfaces the open question at the top instead of pretending everything finished.

COne module clock, done rows frozen
There is exactly one ticking clock in the module — the elapsed in the header, the single thing still happening. Every row carries a frozen, stamped duration the moment it settles, and even a live row shows a stamped “started Ns ago” rather than a churning per-row counter. Only genuinely-live work gets the ⟳ and the one breathing dot. Trade-off: you lose a live per-row stopwatch (some users like watching a slow child's number climb); you gain a calm module where one number moves, not eight.

Stale / terminal-unknown — the module clock stops, the dot is gone
Subagents (3)✓ 2 done · ? 1 unknownran 2:31 · ended 6m ago

When the session is no longer live the one moving thing — the module clock + dot — stops and is replaced by a settled span ("ran 2:31 · ended 6m ago"). Nothing in the module animates. The unknown child keeps its frozen ~0:51 and an honest "?".

DGlyph-strip sparkline
The whole fan-out collapses to a dense strip of cells — one per child, grouped worst-first — so the shape of the fan-out is legible at a glance whether there are 8 children or 80. A red cell or a breathing blue cell jumps out; the strip is the overflow device, so there is never a run-on line or a truncated tail. Click to expand the full rows. Trade-off: the strip alone doesn't tell you which child failed (you expand for that); strongest as a scannable header on a big fan-out, weaker for a two-child run where rows are already tiny.
