Mockup #5 — Thinking block

The thinking block is the quietest layer in the transcript: collapsible, neutral, never out-shouting the agent's prose. Four directions for a calm streaming state and a reflow-free, duration-ranked collapsed state.

Fixes for the shipped block: (1) it streams open & growing — a moving italic panel that reflows the prose below on every token; (2) it collapses to "Thought for Ns" with a layout jump; (3) collapsed lines look identical regardless of think duration, with no gist of what was reasoned.
Targets: reflow-free collapse · duration-ranked lines · gist preview · calm streaming.

AReserved-slot collapse

The thinking line lives in a fixed-height slot the size of its eventual collapsed form. While streaming it shows a one-line teleprompter tail (newest words on the right); the slot never grows, so the prose below never moves. Collapse is a no-op on layout — the slot is already the right height. Tradeoff: you only ever see the trailing fragment live, not the full reasoning until you expand — least context while it thinks.

BFixed-height peek window

Live reasoning tails inside a short fixed-height window (last few lines scroll up, older ones fade at the top). The window's height is constant, so streaming causes no reflow; collapse swaps it for the one-line summary in roughly the same footprint. Tradeoff: a small scrolling region is more motion than A or C — it reads as "alive" but a restless reader's eye may be pulled to it.

CCrossfade to "Thought for Ns"

DDuration-weighted prominence + noun-phrase gist

Collapsed lines are ranked by think effort: a long, hard think earns a slightly higher contrast tier and a longer duration meter; a quick think recedes nearly to a whisper. Each carries a noun-phrase gist of the topic, so a stack of thoughts is scannable by where the model spent its time. Tradeoff: introduces a 3-step weight ladder (more rules to tune); must stay disciplined so even the "long" tier never rivals the prose.
