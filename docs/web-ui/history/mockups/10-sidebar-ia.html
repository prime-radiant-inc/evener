#10 — Sidebar IA

The #1 wayfinding defect. The shipped sidebar tops the list with a flat LIVE rail that duplicates the ACTIVE tier — the same live sessions appear twice, so the eye double-counts and the project structure is buried. Repeated-title sessions (describe this image ×5) sprawl as identical rows; the project rollup is a single dot that can't say "how many need me"; and there is no persistent "you are here" row. Each alternative is a full sidebar over the same data (Active / Recent / Older / Test runs; live + needs-you + idle sessions; de-weighted folded subagents; a five-deep cluster of repeated titles; one selected row) so the four fixes are directly comparable. Every status marker is shape + glyph + color (round live · diamond needs-you · square idle) so it survives colorblindness.

ADelete the LIVE rail — Active is the live home
The flat LIVE rail is removed entirely; the Active tier is the single home for everything live or needs-you, ranked project-first. Each project header carries a magnitude rollup (e.g. 2 ⟳ · 1 !) instead of one ambiguous dot, so "how many need me" is legible without expanding. Repeated titles fold into one cluster. + Zero duplication; the simplest mental model; one place to look. − Users habituated to a top "what's live" glance must learn that Active already is that glance.
