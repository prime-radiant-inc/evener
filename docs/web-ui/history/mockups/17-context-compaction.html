#17 — Context pressure & compaction

Two invisible problems. The context readout is a raw mono number (the shipped ctx 23k / 272k tokens) with no threshold semantics; and serf's context-strategy=compact fires an automatic summarization that silently reshapes the transcript, dropping detail with no UI marker. Four directions, each pairing a pressure gauge with a compaction-lifecycle treatment.

Held constant: color means "needs your eye" — the gauge is the settled, expected state, so it stays neutral until ~80% and only crosses to amber near the edge (paired with a glyph, colorblind-safe). The gauge must be legible without being a permanent attention magnet. Compaction is a lifecycle event you can see, locate, and inspect — never a silent rug-pull. The number is sans tabular-nums (a human reads it); only the model id and token counts stay mono.

AQuiet gauge · coloring only near the edge
The number becomes a small settled bar + percentage in the composer bar, next to the model chip. At low pressure it is a quiet neutral hairline you can ignore; only past ~80% does the whole gauge shift register to amber + a ⚠ glyph, once. Compaction lands as a quiet neutral system one-liner in the transcript — "Context compacted · 41 turns → summary" — a done event that recedes, expandable for the detail. Trade-off: the most restrained option — the gauge is so calm a user who never looks down may still be surprised by compaction; relies on the amber threshold doing its job. Lowest ink, lowest interruption.

DPre-emptive amber nudge · compact before it's silent
The gauge behaves like A's quiet bar — but crossing ~80% also docks an amber nudge above the composer: "Context ~86% — auto-compaction will fire soon" with Compact now (blue, interactive) and Keep going (quiet). This is the one place amber + an action earns its keep: it puts the decision in the user's hands before detail is dropped, turning a silent event into a consented one. Trade-off: the most agency, the most honest about the impending loss — but it is a blocking-ish interruption near the limit, and if shown too eagerly it becomes nag-fatigue (must fire once, near the edge, and stay dismissed).
