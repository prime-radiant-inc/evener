#9 — Subagent navigation & nesting

Four directions for the in / out model: how you open a subagent's transcript and, just as important, how you stay oriented and get back to the parent. Plus the unsolved nesting case — a subagent that itself fans out — where a deep failure must never hide behind a green parent.

Held constant: conversation leads, the subagent module is the one emphasized box; done recedes (neutral), running draws the eye (blue), needs-you (amber) and failure (red) stand out, each paired with a glyph. The worst-state rollup rule: a parent row's status chip is colored by its worst descendant, so a buried ✕ reddens every ancestor. Getting back out is a first-class affordance, never a guess.
AParent breadcrumb banner
Keep the existing hard nav to /s/<ref>, but pin a breadcrumb banner to the top of every subagent workspace. Each crumb is a real link up the chain; the deepest crumb carries the live worst-state rollup so you can see, from a child, that one of its children failed. Trade-off: the smallest change (ships first, survives a real page reload, deep-linkable), but every hop is a full navigation — you lose the parent's live transcript while you're away.

BSlide-over (parent stays live)
"view →" opens the child in a slide-over panel over the parent — no page nav. The parent transcript stays mounted and keeps streaming behind a scrim; close (Esc, ✕, or click-out) returns you exactly where you were. A nested child opens a second slide-over on top (a shallow stack). Trade-off: great for a quick peek without losing your place, but the panel is narrower than a full workspace and deep stacks get cramped; needs a deep-link fallback for reload.

CInline accordion
"view →" becomes a disclosure twisty: the child's transcript expands in place, indented inside the parent's module — no navigation, nothing to back out of. A nested subagent nests one more level of indent. Worst-state rollup is intrinsic: a collapsed red descendant still shows its chip on the parent row, and you drill by expanding. Trade-off: zero orientation cost and the full ancestry is always on screen, but deep or chatty children push the parent's later turns far down; best capped to ~2 levels before falling back to slide-over/nav for the deep stuff.

DTabbed session stack + rollup tree
"view →" opens the child as a tab alongside the parent (like editor tabs). The parent tab stays put; nested children add deeper tabs marked with a ↳. Each tab's glyph reflects that session's worst-state rollup, so a tab reddens when something deep in it failed — and a dedicated Map tab shows the whole forest as one rollup tree where a buried ✕ lights every ancestor. Trade-off: the most powerful for juggling several deep sessions and for "where's the failure?" triage, but the heaviest chrome — overkill for a session with two flat subagents.
