## Interpretation (hand-authored) — this is where the note earns its keep

With **6–8 distinct facts** buried through heavy interleaved bulk, the baseline gpt-5.5
summarizer kept only **46%** of them (`baseline retention 0.46`) — it **drops ~54% of the
facts** when it has to carry many. The judge rated those baseline handoffs **2.40/5**
(facts lost → a fresh agent could not reliably continue).

**The agent's note rescues exactly that loss.** Arm B (note + baseline summary) carries
all facts verbatim and the judge score jumps to **4.10** — a **+1.70** lift, nearly
doubling handoff quality. Note + steering (C) reaches **5.00**.

**This is the note's value, finally measured.** The single-needle runs hid it because one
salient fact always survives even a weak model; the moment the agent must carry *many*
facts through compaction — the situation the feature targets — the baseline loses about
half of them, and the note preserves them.

### Caveat: the `steered-summary retention 0.00` is a measurement artifact, not a result
The exact-string retention metric shows the steered *summary* (no note) retaining 0% of
facts in every case. That is **not** "steering makes the summary worse." The judge scored
arm C (note + **steered** summary) at **5.00**, strictly above arm B (note + **baseline**
summary) at **4.10** — if the steered summary were empty or useless, C would equal B. The
steered summary is non-empty and *better*; it simply **paraphrases** the facts rather than
copying them verbatim, so an exact-substring match misses them. The baseline's default
prompt preserves text more verbatim (hence its 0.46 exact-match floor). **Exact-string
retention is a valid lower bound only for verbatim-copying output; the judge captures the
semantic retention that the steered, paraphrasing summary actually achieves.**

## Cross-run synthesis (all three controlled runs)

| Run | baseline fact retention | judge A → B → C | what it showed |
|---|---|---|---|
| single-needle gpt-5.5 | 1.00 (1 fact) | 4.09 → 4.09 → 5.00 | corpus too easy; only **steering** showed (+0.91) |
| single-needle gpt-5.4-mini | 1.00 (1 fact) | 5.00 → 5.00 → 5.00 | weak model still keeps 1 fact; weak judge erases all signal |
| **multi-needle gpt-5.5** | **0.46 (6–8 facts)** | **2.40 → 4.10 → 5.00** | **the note rescues the ~54% the baseline drops; +1.70 judge** |

**Bottom line for the feature:** the agent-authored note delivers real, measured value
**precisely in the multi-fact / long-context regime it is designed for** — where a single
post-hoc summary cannot hold everything and silently drops about half the facts. On easy
single-fact cases the note is redundant (the summarizer keeps the one fact anyway). The
steering (`compaction_instructions`) helps quality on top of either. This is serf-specific
empirical support for shipping both the note and the instruction path — with the honest
boundary that the value scales with how much the agent needs to carry through compaction.
