# host_request_methods.txt — the methods the hub web UI forwards to a selected
# remote host through evener/host/request, and the single checked-in list BOTH
# languages' tests read. Lines beginning with '#' are comments; every other
# non-empty line is one method name, spelled exactly as the AppWire catalog
# spells it (appwire's Method* constants / the generated METHOD_NAMES).
#
# appwire-client/typescript/hostRouting.ts exports the SDK discovery subset.
# The browser integration test at frontend/src/stores/hostRouting.test.ts
# compares it with this fixture in both directions, so changing the SDK subset
# alone cannot silently change the product contract.
#
# app_host_admin_test.go checks that every fixture entry is in the proxy's
# allow-list and is actually forwarded. The SDK's adjacent routing unit tests
# exercise the shared helper without reading this app-owned fixture.
#
# The Go allow-list is a SUPERSET of this list: it also carries the remote
# settings panes' provider/launch/marketplace/plugin/auth methods, which the
# spawn form never issues. What is listed here is the spawn form's discovery set
# (component 06 §"Frontend changes", acceptance criterion 10; component 07
# §"Proxy method"): model discovery, harnesses, launch resolution/schema, path
# completion/validation, directory creation, recent projects, the spawn slash
# catalog, the branch/location git HEAD read, the plugin-preview panel, and the
# provider-instance list. A method removed from the product should be removed
# from here — which fails on both sides until the other side is updated too.
