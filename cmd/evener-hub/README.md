# Evener Hub

The `evener hub` subcommand is Evener's orchestrator. Its web UI is the default interactive
surface for driving the agent.

- New users: start with [docs/getting-started.md](../../docs/getting-started.md).
- Operators: the hub runbook (config files, credentials, supervised
  operation, smoke checks) lives at
  [docs/evener-hub.md](../../docs/evener-hub.md).
- Contributors: see
  [docs/developing-evener/README.md](../../docs/developing-evener/README.md)
  for building and testing this repo.
