3. **Tokenizer handling**  
   Full GPT-2 byte-level BPE parsing from `vocab.bpe` + encoder json is also substantial. Minimal tiny programs usually hardcode vocab or use preprocessed token tables.

4. **Concrete approach I’d use if format is adapted**
