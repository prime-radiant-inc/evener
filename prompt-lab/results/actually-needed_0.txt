Implementation plan (practical and minimal):

1. **Use TensorFlow checkpoint reader by shelling out to Python once**
   - A TF `.ckpt` is not a flat raw tensor file; parsing it in pure C would exceed 5KB quickly.
   - Keep C dependency-free by invoking `python3` via `popen()` to:
     - load variables from checkpoint (`tf.train.load_checkpoint`)
     - dump all needed tensors in a compact plain-text stream.
   - C parses that stream and stores tensors in memory.

2. **Assume GPT-2 124M canonical shapes**
   - `n_vocab=50257, n_ctx=1024, n_embd=768, n_head=12, n_layer=12`.
   - Read tensors by TF names from checkpoint:
     - `model/wte`, `model/wpe`, `model/ln_f/{g,b}`
     - per-layer: `model/h%d/ln_1/{g,b}`, `attn/{c_attn/{w,b},c_proj/{w,b}}`, `ln_2/{g,b}`, `mlp/{c_fc/{w,b},c_proj/{w,b}}`.

3. **Implement byte-level BPE tokenizer in C**
   - Read `vocab.bpe` merges.
   - Reconstruct GPT-2 byte->unicode map and encoder ranks.
   - For compactness, use straightforward greedy pair merging with rank lookup in linear table (slow but okay for short prompt/20 tokens).
   - Also build token string table by asking Python to dump encoder JSON from checkpoint directory (or fallback to `gpt2` package style files if present).  
   - Since user supplies `.bpe` only, embed the standard GPT-2 encoder base64-like byte tokens generation and derive ids from merges+bytes (minimal compatible path).

4. **Forward pass**
   - No KV cache for simplicity (recompute full context each step).
   - For each layer:
     - LN
     - QKV projection
     - causal self-attention
     - output projection + residual
     - LN
     - MLP GELU + projection + residual
   - Final LN + logits = hidden * `wte^T`.
   - Argmax over vocab.

5. **Sampling loop**
   - Encode input prompt to token ids.
   - Repeat 20 times:
     - run forward on full current token list
     - argmax next token
     - append
   - Decode new tokens and print continuation text.

6. **Size control (<5000 bytes)**
   - Tight C style, short identifiers, minimal error checks.
   - Use float math and naive loops.
   - Avoid fancy data structures.
   - Reuse buffers aggressively.
   - Use Python helper script embedded as one-liner strings to keep C small.
