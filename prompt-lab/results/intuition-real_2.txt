## Practical implementation plan (if constraints are relaxed)

1. **Model conversion step (offline)**
   - Convert TF `.ckpt` into a flat binary format:
     - header: `n_layer, n_head, n_embd, n_ctx, vocab_size`
     - contiguous tensors in known order.
   - Export vocab + merges from GPT-2 assets.

2. **Tokenizer**
   - Byte-level preprocessing (GPT-2 bytes-to-unicode map).
   - Greedy BPE merge loop using rank table (hash map).
   - Encode prompt to token ids.

3. **Inference**
   - Load weights into memory.
   - For each new token (20 steps):
     - Embed token + position.
     - Run each transformer block:
       - LayerNorm
       - QKV projection
       - causal self-attention
       - output projection
       - residual
       - LayerNorm
       - MLP (gelu)
       - projection + residual
     - final layernorm + lm_head logits.
     - argmax token.
   - Append token and continue.

4. **Decode**
   - Token IDs back to byte sequence/string and print only continuation.
