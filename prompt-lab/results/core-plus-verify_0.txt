### Implementation plan (practical, correct route)

1. **Parse TensorFlow checkpoint format**
   - Read the `.ckpt` index/data records (TF checkpoint is not a raw contiguous tensor dump).
   - Build mapping from tensor names to offsets/shapes.
   - Extract all GPT‑2 tensors:
     - token embeddings `wte`, positional embeddings `wpe`
     - per-layer `ln_1`, `attn/c_attn`, `attn/c_proj`, `ln_2`, `mlp/c_fc`, `mlp/c_proj`
     - final `ln_f`, and tied LM head.

2. **Load GPT‑2 hyperparameters**
   - Infer `n_layer, n_head, n_embd, n_ctx, vocab_size` from tensor shapes.

3. **Load BPE vocab/merges**
   - Parse `vocab.bpe` merge ranks.
   - Also require encoder JSON (token->id map) in normal GPT‑2 setups; if absent, construct from checkpoint/vocab assets if available.
   - Implement byte-level pretokenization and reversible byte encoder.

4. **Tokenize prompt**
   - Convert UTF‑8 bytes to GPT‑2 byte-level symbols.
   - Apply BPE merges greedily by rank.
   - Map final symbols to token IDs.

5. **Forward pass**
   - For each generation step:
     - Embed last context window tokens (`wte + wpe`)
     - Run transformer blocks:
       - layer norm
       - masked multi-head self-attention
       - residual add
       - layer norm
       - MLP (GELU)
       - residual add
     - final layer norm
     - logits via tied embedding matrix.
   - Use **argmax** over logits for next token.

6. **Autoregressive loop**
   - Generate exactly 20 tokens.
   - Append token each step; apply context truncation if > `n_ctx`.

7. **Detokenize output**
   - Convert generated token IDs back through decoder map.
   - Reverse byte-level encoding and print UTF‑8 continuation.

8. **Performance/memory**
   - Use `float` arrays; optionally KV cache for speed.
   - Single-threaded, no external dependencies, compile with `gcc -O3 -lm`.
