### Why
A correct solution needs all of:
1. TensorFlow checkpoint parsing (`.index` + sharded `.data` or monolithic variant handling).
2. GPT‑2 BPE tokenizer (byte encoder/decoder + merge-rank table parsing from `vocab.bpe`).
3. Full transformer forward pass:
   - token + positional embeddings  
   - 12 blocks (for 124M): LN, QKV projection, masked attention, projection, MLP, residuals
   - final LN + tied softmax logits
4. Argmax decode loop for 20 tokens.

Even stripped, the numeric core alone is far larger than 5KB source when written in plain C with no external libs, and runtime memory/IO logic for checkpoint formats and tokenizer pushes far beyond that.

## Practical implementation plan (that will work if size limit is relaxed)

1. **Switch model format**: pre-convert `.ckpt` into a tiny custom binary blob laid out in exact tensor order and dtype `float32`.
2. **Tokenizer prep**:
   - Prebuild `encoder.json` → token-id map as a compact binary hash table.
   - Parse `vocab.bpe` merge ranks into a compact rank table.
3. **C runtime**:
   - mmap/read binary weights.
   - Byte-level pretokenization + BPE merges.
   - Implement GPT‑2 124M forward with scratch buffers reused per layer.
   - Argmax over logits each step.
4. **Generate**:
   - Encode input prompt.
   - Run causal decoding for 20 steps, append token each step.
   - Decode bytes back to UTF‑8 stream.
