Plan (step-by-step)
1. **Use TensorFlow checkpoint reader-free approach**: parse the `.ckpt` as a flat binary blob by scanning for contiguous float arrays in the known GPT-2 tensor order/shape (124M config), instead of depending on TF libraries.
2. **Hardcode GPT-2 124M architecture**:  
   - `n_vocab=50257, n_ctx=1024, n_embd=768, n_head=12, n_layer=12`  
   - infer all parameter sizes and map pointers into loaded checkpoint memory.
3. **Read vocab/bpe minimally**: parse `vocab.bpe` merges into rank table and construct byte-level tokenization pipeline compatible enough to tokenize the prompt and decode output.
4. **Implement byte-level BPE**:
   - byte-to-unicode mapping
   - pre-token split by GPT-2-ish regex approximation (simple whitespace + non-whitespace chunks)
   - iterative pair-merge by rank
5. **Implement transformer forward pass** for one step at a time with KV cache:
   - token + position embeddings
   - per-layer LN → self-attn (QKV projection, causal via cache) → proj → residual
   - LN → MLP (FC, GELU, proj) → residual
   - final LN + tied logits with token embedding
6. **Argmax sampling**: pick max logit token each step.
7. **Generate 20 tokens** continuing from prompt.
8. **Keep code small (<5000 bytes)**:
   - aggressive terseness, compact helpers, fixed-size buffers
   - omit error niceties
   - minimal parsing assumptions
