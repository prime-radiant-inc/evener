Plan (concise, practical):

1. **Use TensorFlow v1 checkpoint reader minimally**  
   - Parse the `.ckpt` by reading TF checkpoint index/data records enough to locate tensors by name.
   - Load only GPT-2 tensors needed for inference:
     - `model/wte` (token embeddings)
     - `model/wpe` (pos embeddings)
     - Per-layer: `ln_1/*`, `attn/*`, `ln_2/*`, `mlp/*`
     - Final `ln_f/*`
   - Store as `float*` in host memory.

2. **Parse GPT-2 BPE vocab file**  
   - Read merges (`vocab.bpe`) and build rank map.
   - Build byte encoder/decoder tables used by GPT-2 byte-level BPE.
   - Reconstruct token <-> string vocabulary from checkpoint (or expected companion vocab list if embedded path convention is used).
   - Implement encoder:
     - split to GPT-2 regex-like chunks
     - byte-encode
     - BPE merge by rank
     - map to token ids
   - Implement decoder:
     - token ids -> merged byte string -> UTF-8 bytes.

3. **Implement forward pass for single batch, autoregressive**  
   - Shapes inferred from weights (`n_layer`, `n_embd`, `n_head`, `n_vocab`, `n_ctx`).
   - For each step:
     - token embedding + positional embedding -> residual stream
     - loop layers:
       - LayerNorm
       - QKV projection
       - causal self-attention (only up to current position)
       - output projection + residual
       - LayerNorm
       - MLP (FC, GELU, FC) + residual
     - final LayerNorm
     - logits = hidden · `wte^T` (tied weights)
     - argmax next token.

4. **Generation loop**  
   - Input prompt from argv[3], encode to ids.
   - Run model over prompt to prime KV/state (or recompute naively each step if code-size constrained).
   - Generate exactly 20 tokens by greedy argmax.
   - Print prompt + decoded generated continuation.

5. **Keep file under 5000 bytes**  
   - Aggressively minify identifiers/whitespace.
   - Prefer straightforward loops and static helpers.
   - Avoid external deps; only libc + math.
   - If full TF ckpt parse exceeds size, implement strict parser for the exact GPT-2 checkpoint layout and fail otherwise.
