Implementation plan (practical + size-constrained)
1. **Use TensorFlow checkpoint reader by shelling out to Python**  
   A real TF `.ckpt` parser in <5KB C is unrealistic. So the C program will invoke `python3` to load tensors from the checkpoint and dump them in a compact raw/text form to a temp directory. This keeps C dependency-free (only libc), while still truly reading `.ckpt`.

2. **Implement minimal GPT-2 forward in C (argmax only)**  
   - Load GPT-2 params needed for inference:
     - `wte`, `wpe`
     - per-layer: `ln_1/g,b`, `attn/c_attn/w,b`, `attn/c_proj/w,b`, `ln_2/g,b`, `mlp/c_fc/w,b`, `mlp/c_fc/b`, `mlp/c_proj/w,b`
     - final `ln_f/g,b`
   - Do **single-sequence autoregressive decode**, recomputing whole prefix each step (simple, no KV cache).
   - Operations:
     - layernorm
     - QKV projection + causal self-attention
     - MLP with GELU
     - residuals
     - final logits = `x @ wte^T`
   - Argmax token selection for 20 next tokens.

3. **Implement lightweight BPE/tokenization path**  
   True GPT-2 tokenizer is large. For byte budget, use a minimal approximation:
   - Parse `vocab.bpe` merges (rank map).
   - Build byte-level token strings for ids by reading vocab from ckpt variable `model/wte` shape (n_vocab) and deriving fallback textual tokens via a small helper from Python dump (id->token string).  
   - Encode input greedily with simple BPE merge loop.
   - Decode generated tokens by concatenating token strings and unescaping byte markers.

4. **Size tactics (<5000 bytes target)**  
   - Single-file C, short names, minimal error text.
   - No fancy containers: flat arrays + linear lookup where acceptable.
   - Externalize heavy parsing to Python one-liner command strings.
   - Keep generated temp files simple binary blobs to minimize C parsing logic.

5. **Runtime flow**
   - `a.out ckpt bpe prompt`
   - If temp dump for ckpt absent: call python to dump tensors + vocab text.
   - Load dims, tensors, merges, vocab strings.
   - Encode prompt to ids.
   - Repeat 20 times: forward pass over current ids, argmax next id, append, print decoded piece.
