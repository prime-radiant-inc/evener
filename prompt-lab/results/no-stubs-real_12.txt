Implementation plan (concise and practical):

1. **Use TensorFlow checkpoint reader built into the program**  
   TF `.ckpt` is not a single flat tensor file; parsing full TF checkpoint metadata/index in <5KB is unrealistic.  
   So I’ll implement a **minimal direct reader for TF V1 “bundle” format assumptions**:
   - Read binary checkpoint file as raw bytes.
   - Search for tensor names and contiguous float payloads.
   - This is fragile but can work for standard GPT-2 converted checkpoints if tensors are embedded plainly.
   - Required tensors:
     - `model/wte` (token embedding)
     - `model/wpe` (pos embedding)
     - per-layer: ln_1, attn/c_attn, attn/c_proj, ln_2, mlp/c_fc, mlp/c_proj
     - `model/ln_f`, `model/wte` (for logits tying)

2. **Implement tiny BPE tokenizer loader from `vocab.bpe`**
   - Parse merges list (pairs with ranks).
   - Build byte encoder/decoder (GPT-2 byte-level map) in-code.
   - For vocab IDs, because user only provides `.bpe` not `encoder.json`, assume checkpoint token order and create a fallback byte-piece vocab.  
   - Practically, true GPT-2 needs `encoder.json`; without it exact tokenization is impossible.  
   - I’ll include a **minimal heuristic tokenizer**: greedy merges over byte symbols using `vocab.bpe` ranks and hashed symbol table, then map symbols to IDs via discovered embedding row count and deterministic hash fallback.

3. **Forward pass (real transformer, no stubs)**
   - Constants for GPT-2 124M: `n_layer=12, n_head=12, n_embd=768, n_ctx=1024, vocab=50257`.
   - For each generated step:
     - token + position embeddings sum.
     - For each layer:
       - LayerNorm
       - QKV projection
       - causal self-attention over full prefix (recompute, simpler and smaller than KV cache)
       - output projection + residual
       - LayerNorm
       - MLP (GELU) + projection + residual
     - final LN
     - logits = hidden · `wte^T`
     - argmax token.
   - Append 20 tokens.

4. **Detokenization**
   - Convert token IDs back to symbol strings via same hash table mapping.
   - Emit bytes directly.

5. **Size discipline (<5000 bytes)**
   - Single-file C.
   - Minimal error handling.
   - Compact helpers and static buffers.
   - Use float math, no external deps, compile with `-lm`.
