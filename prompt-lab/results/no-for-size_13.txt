2. **Tokenizer**
   - Byte-to-unicode map (GPT‑2 style).
   - Read merges from `vocab.bpe`.
   - Greedy BPE encode input text into token ids.
   - Build inverse vocab for decoding generated ids.

3. **Model runtime**
   - `float` tensors.
   - Transformer block loop:
     - layernorm
     - QKV projection
     - causal self-attention (with KV cache)

     - MLP (gelu)
     - output projection + residual

4. **Generation**
   - For each next token (20 steps):
     - run one-step decode with cache,
     - argmax logits,

5. **Performance/size cleanup**
   - static arrays + malloc only where needed.
   - no external dependencies beyond libc/libm.
