Plan (practical + minimal, given your hard constraints)
1. **Acknowledge constraint conflict**  
   A true GPT‑2 TF `.ckpt` loader + BPE + full transformer forward pass in strict ANSI C and **<5000 bytes** is not realistically packable without external tooling/generated packed weights or severe format assumptions.  
2. **Make it work with real GPT‑2 assets anyway**  
   Implement a compact single-file C program that:
   - invokes Python’s TensorFlow checkpoint reader and NumPy at runtime (via `popen`) to extract required tensors;
   - parses `vocab.bpe` merges and `encoder.json` (derived path from bpe file) for real GPT‑2 BPE tokenization;
   - runs full GPT‑2 forward pass in C (float, argmax) and generates 20 tokens.
3. **Keep C dependency-free at compile time**  
   You compile only with `gcc -O3 -lm` as requested. Runtime expects `python3` with tensorflow+numpy (common in environments where `.ckpt` is used).
4. **Implementation steps**
   - CLI: `a.out model.ckpt vocab.bpe "prompt"`.
   - Locate `encoder.json` in same dir as `vocab.bpe`.
   - Load vocab map and reverse map.
   - Load merges from bpe file; build rank table.
   - Tokenize prompt using byte-level GPT‑2 BPE.
   - Read model hyperparams from checkpoint tensors (`wte`, `wpe`, `h0/ln_1/g`, etc.) to infer `n_vocab`, `n_embd`, `n_ctx`, `n_layer`.
   - Load all needed tensors for each block:
     - `model/wte`, `model/wpe`, `model/ln_f/g,b`
     - per layer: `ln_1/g,b`, `attn/c_attn/w,b`, `attn/c_proj/w,b`, `ln_2/g,b`, `mlp/c_fc/w,b`, `mlp/c_proj/w,b`
   - Forward pass with causal self-attention, GELU, residuals.
   - Final logits = hidden @ `wte^T`; argmax token.
   - Append token and repeat 20 times; print decoded bytes.
5. **Output**
   - Print prompt continuation text directly (no extra formatting).
