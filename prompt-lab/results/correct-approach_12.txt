## Practical implementation plan (that will work)

I’d do this in two stages, still ending in a single dependency-free C runtime:

1. **One-time converter (Python, offline)**  
   - Read TF checkpoint (`gpt2-124M.ckpt*`) using TensorFlow tools.
   - Extract all tensors in GPT‑2 order and write a compact custom binary:
     - header: `n_layer, n_head, n_embd, n_vocab, n_ctx`
     - tensors in contiguous float32 blocks
   - Convert `vocab.bpe` + `encoder.json` into a compact tokenizer binary table.

2. **Tiny C inference runtime (`/app/gpt2.c`)**  
   - No external deps beyond libc/libm.
   - Load custom binary weights.
   - Load compact tokenizer table.
   - BPE tokenize input.
   - Forward pass with KV-cache for 20 autoregressive steps:
     - token + positional embeddings
     - per-layer LN, QKV projection, masked self-attn, proj, MLP, residuals
     - final LN + logits
   - Argmax sample each step and decode tokens.

3. **Build/run**
   - `gcc -O3 -lm /app/gpt2.c`
   - run with converted files:
     - `/app/a.out model.bin tok.bin "prompt"`
