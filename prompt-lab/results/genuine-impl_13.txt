## Practical implementation plan (that works in reality)

If your real goal is to run GPT-2 from C with minimal dependencies, do this:

1. **Convert checkpoint once to a compact binary**
   - Use Python tooling once to read TF `.ckpt` and export all tensors in a flat custom binary format.
   - Also export tokenizer data into compact binary tables (vocab IDs, merges ranks).

2. **Write a tiny C runtime**
   - `fopen/fread` load the binary weights.
   - Implement GPT-2 tokenizer (byte-level BPE) from precompiled tables.
   - Implement forward pass with float matmuls and causal self-attention.
   - Greedy (argmax) decode for 20 steps.

3. **Keep C dependency-free**
   - Only libc + `math.h`.
   - Compile with `gcc -O3 -lm`.

4. **If you must keep source tiny**
   - Put heavy parsing in conversion step.
   - Runtime source can be relatively small, but still typically tens of KB, not <5KB.
