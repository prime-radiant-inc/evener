The checkpoint format alone (TensorFlow checkpoint index/data sharding, tensor names, dtype/shape metadata) requires substantial parsing logic and binary handling, and GPT‑2 124M inference needs matrix ops over ~124M params—far beyond what fits in 5KB C source while still handling `.bpe` tokenization.

Given your “must work” constraints, the only viable implementation is to target a **much simpler custom flat binary format** (or a tiny model), not raw TF `.ckpt`.

   - byte-to-unicode map

3. **Model forward**

     - token + positional embeddings

     - QKV projection
     - causal attention

     - residuals

4. **Argmax sampling**
   - At each step, compute logits for last position
   - pick max index

5. **Output**

int main(int c,char**v){

  FILE*g=fopen(bp,"rb"); if(!g) die("cannot open bpe");
  fseek(g,0,SEEK_END); long m=ftell(g); fclose(g);
