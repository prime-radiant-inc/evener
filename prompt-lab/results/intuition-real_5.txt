## Implementation plan (realistic and buildable)

1. **Convert checkpoint once to a flat custom binary**
   - Use Python/TF script offline to read `gpt2-124M.ckpt` and dump tensors in fixed order:
     - token embedding `wte [vocab,n_embd]`
     - positional embedding `wpe [n_ctx,n_embd]`
     - for each layer: ln_1 g/b, attn c_attn w/b, c_proj w/b, ln_2 g/b, mlp c_fc w/b, c_proj w/b
     - final ln_f g/b
     - optionally tied lm_head = wte
   - Write header with dims so C can mmap/fread directly.

2. **Convert tokenizer assets**
   - From `encoder.json` + `vocab.bpe`, generate compact binary:
     - token string table + id
     - merge ranks hash table
   - C code loads this and performs byte-level BPE encode/decode.

3. **C inference core**
   - fp32 only.
   - Single-token autoregressive loop for 20 steps.
   - For each layer:
     - layernorm
     - qkv projection
     - causal self-attention against KV cache
     - projection
     - residual
     - layernorm
     - MLP (GELU)
     - projection
     - residual
   - Final ln + logits (`h @ wte^T`), argmax token.

4. **Argmax sampling**
   - Deterministic: choose highest logit each step.

5. **CLI behavior**
   - `/app/a.out model.bin tok.bin "prompt"` (or keep your names and convert in place).
   - Encode prompt, run forward over prompt to prime cache.
   - Generate 20 tokens, decode and print continuation.
