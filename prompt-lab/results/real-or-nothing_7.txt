### Why (briefly)
A **dependency-free single C file under 5000 bytes** that:
1. parses a TensorFlow `.ckpt`,

## Implementation plan (practical, works if constraints are relaxed)

### Step 1: Choose a simpler weight format
Convert the TF checkpoint to a flat binary layout (e.g., `ggml`, `npz` with known order, or custom packed float32 file) so C can memory-map/read sequentially.

### Step 2: Preprocess tokenizer assets
Convert `vocab.bpe` + GPT-2 encoder JSON into:
- `token -> string`
- merge ranks table
for fast lookup. Store in compact binary tables.

### Step 3: Write minimal GPT-2 inference core in C
Implement:
- token + position embeddings
- per-layer: layernorm, QKV projection, causal self-attention, output projection, MLP (GELU), residuals
- final layernorm + logits projection

All float32, no dependencies beyond `math.h`.

### Step 4: Add argmax sampling loop
- Encode prompt into token ids
- For 20 steps:
  - run forward on full context (or KV-cache if added)
  - choose `argmax(logits_last)`
  - append token

### Step 5: Decode tokens back to bytes/text
Use GPT-2 byte-level decoder to print exact continuation text.

### Step 6: Optimize size
- Remove error verbosity
- Compact parsing
- Use static inline math helpers
- Strip optional features
