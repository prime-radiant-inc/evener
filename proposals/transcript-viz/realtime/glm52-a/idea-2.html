What you see at a glance, live: as turns stream in, the grid grows column-by-column from the right; the active bucket's column pulses with a glowing green outline to mark where the session is right now. The active-row label highlights the current tool type. The streaming ticker narrates each event as it arrives (tool_results, steering, compaction, failure). Live questions answered: what pattern is forming right now (burst, stall, retry loop)? what just changed? is current activity normal for this session? Phase transitions (exploration → delegation → integration) and tool-mix shifts read as spatial patterns — no clicking needed to read them. A mini-icicle on top shows the 3-level delegate tree along the same time axis; a new child delegate node glows green and grows rightward as it spans turns.
