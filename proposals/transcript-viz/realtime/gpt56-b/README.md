# Realtime transcript visualization proposals — semantic zoom and narrative

These mockups reinterpret the session visualization as an always-on companion while an agent is running, not as a retrospective archive browser. Each starts with a mature 247–251-turn session so long-session behavior is visible immediately, then autoplays a synthetic durable stream containing assistant turns, tool starts/results, delegate spawn/report, background job notifications, bounded watch triggers, context growth, a compaction, and an evidence-read retry. Every file is standalone, has inline CSS/JavaScript only, and runs from `file://`; use Pause, Reset, speed, and semantic-zoom controls to inspect the update model.

## Idea 1 — Live Chronicle

**Realtime comprehension question:** What is the coherent story so far, which chapter is being written, what just arrived, and what is the agent attempting now? Live Chronicle renders a self-revising technical document: settled chapters remain stable while the running synopsis, current chapter prose, evidence tail, context ring, and marginal “attempting now” HUD update on every event. The update model applies each durable frame to four semantic projections—synopsis, chapter draft, bounded recent turns, and live evidence—without rewriting old chapter geometry. It scales because 250+ turns remain compressed into a fixed outline and proportional ribbon, while only the current chapter and seven-to-nine newest turns materialize at high detail.

## Idea 2 — Nowline Loom

**Realtime comprehension question:** What work is in flight in parallel, which causal branch just settled, and what is the parent waiting for at this exact moment? Nowline Loom gives every parent/delegate/job/watch stream a stable lane; running bars terminate at a green now-line with dashed edges, then detach into settled history when completion frames arrive, while the left narrative and right causal HUD update in sync. The update model advances a bounded time window, promotes consequential arrivals into narrative beats, and records context folds as vertical seams without changing lane identity. It scales because the whole-session density strip absorbs old activity, the 15-minute and latest-turn zooms reuse the same lanes, and only a small causal present remains expanded after 250+ turns.

## Idea 3 — Growing Atlas

**Realtime comprehension question:** How is the shape of the story changing, which narrative region is still provisional, and what active work is making it grow? Growing Atlas continuously recomputes a sequence-preserving cartogram: the live chapter gains area as calls/time/tokens arrive, compaction seams appear, in-flight regions carry a striped “LIVE · GROWING” treatment, and closing verification visibly opens a new audit-and-handoff region. The update model projects every event into three semantic zooms—the bounded story map, packets within the current chapter, and an in-flight “Now” map—while a five-row event tape and HUD explain each rebalance. It scales because the top level never exceeds the session’s small set of narrative chapters, completed regions stabilize, and 250+ underlying turns affect area and totals rather than adding one mark per turn.
