Delegate Cost Matrix — an icicle + ribbon tree

The 3-level delegation tree as an icicle: node width = turn span, depth = delegation level. Inside each node, stacked micro-ribbons show tool-call density (green), token cost (blue), and wall-clock duration (violet) — a red ribbon marks an error. Where cost concentrates is scannable at a glance: a fat dlg_cost_tree node dominates the session, its cyan grandchild carries a red error ribbon, and the root bar spans everything.
