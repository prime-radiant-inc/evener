Trigger Rail RAIL 160px

A 160px spine rail where episodes are rows that compress to slivers behind each compaction fold, non-adjacent causality draws as left-edge brackets, context pressure is a mercury gauge, and user prompts are permanent green rows that jump the transcript.

Realtime comprehension
What it's doing now (pulsing row + NOW zone), what triggered it (causal brackets landing live — red caused-failure, blue steered, teal reported), whether a runaway/cascade is active (left border glows red), context pressure as right-edge mercury that drops at each fold. History literally compacts to slivers behind folds.
Long-session scaling
287 turns → ~20 spine rows; sealed rows collapse to 5px slivers behind each fold, so vertical cost shrinks as the session grows — 10× longer sessions still fit one viewport. Prompt rows are exempt from compression forever.
