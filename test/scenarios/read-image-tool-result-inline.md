# read-image-tool-result-inline: render tool-result image bytes under the producing row

**What this covers**: web UI inline output-image v1 card `read-image-tool-result-inline`. A tool result that already carries image bytes (for example a `read_file` result for a PNG screenshot projected through AppWire `outputImages`) renders as an inline thumbnail below that same tool row. AppWire carries an output-image descriptor only; it must not carry generated file bytes or a base64 payload for file-backed images.

## Pre-state

- Use a local deterministic scenario harness or scripted provider at the LLM boundary; do not use live provider credentials or network access.
- Start a fresh session cwd containing a tiny PNG fixture, for example `fixture.png` created under a temp directory.
- The scripted model turn calls an image-capable local tool such as `read_file` on `fixture.png`, then ends the turn.
- `serf-hub` is serving the session UI with AppWire enabled.

## Steps

1. Open the session in the web UI and wait for the scripted tool call to complete.
2. Locate the completed `read_file` (or equivalent image-reading tool) row in the conversation.
3. Inspect the row for a `.tool-output-images` block containing a `.user-image-card img.user-image-thumb`.
4. Click the thumbnail.

## Expected

- The completed tool row still shows its ordinary textual result/status, and directly below that same row it shows exactly the valid image preview for `fixture.png`.
- The thumbnail source is a same-origin relative descriptor URL generated by the server (for transcript-backed bytes, a stable session image URL such as `/s/<sid>/images/<sha>`). The row must not embed raw generated file bytes or a data/base64 URL for file-backed output.
- Clicking the thumbnail opens `#image-lightbox` for that image.
- Falsification: the transcript shows only text/path output with no clickable image thumbnail under the producing tool row, the thumbnail is attached to a different row, or the descriptor uses an external/protocol-relative URL.

## Cleanup

- Shut down the scripted session and remove the temp cwd/state directory.

## Sharp edges

- This card is for tool-result image bytes already present in transcript/tool-result data. File-discovery behavior for written files is covered by `written-image-inline-after-reload.md` and `shell-generated-image-path-inline.md`.
